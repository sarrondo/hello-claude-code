# Hello Claude Code

## What it does

`hello.py` is a small Python script that prints today's date and a motivational line.

## How to run it

1. Make sure Python 3 is installed:
   ```
   python3 --version
   ```
2. Open Terminal and go to the project folder:
   ```
   cd ~/projects/hello-claude-code
   ```
3. Run the script:
   ```
   python3 hello.py
   ```

You should see something like:

```
Today's date is: Friday, October 30, 2026
Every expert was once a beginner. Keep going!
```
